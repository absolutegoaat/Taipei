# 台北
A Proxy that logs a victims internet usage and is decrypted by installing a root cert on the victims device.

# Usage
* Run proxy (```python(3) index.py```) and get the cert that was exported
* import cert in root cert vault or wtv its called
* configure connection settings to foward to your proxy
* congrats your the national security agency
* Just launch the taipei client and connect to the web server

# Notes
* Use phpmyadmin to access the database and make an api token in the tokens table.
